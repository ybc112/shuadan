# 栖点 Maker v1.1 · U 本位合约模拟工作台

根据提供的网格、机器人列表与参数截图实现的本地中文应用。源码、运行配置和数据均位于此项目目录。

**本版本支持本地模拟交易、币安公开行情，以及真正发往币安的账户只读 API 检查。填入 API 凭据不会启用实盘下单、撤单或平仓；本项目不提供对敲、虚假刷量或用撤单制造虚假流动性的功能。**

## 直接启动

Windows 双击根目录的 **启动工作台.cmd**，浏览器会打开 http://127.0.0.1:4318 。脚本会检查 Node.js、安装缺失依赖、构建页面并在后台启动服务。需要 Node.js 22.12 或更新版本。

修改 API 配置或后端代码后，双击 **重启工作台.cmd**。重启脚本核对端口、PID 和项目归属，先暂停机器人并确认数据保存，再重启本项目的服务。模拟持仓、资金和配置保留，机器人保持暂停。只重复点击“启动工作台”不会替换已经运行的服务。

也可以在 PowerShell 中运行：

```powershell
Set-Location -LiteralPath 'E:\dapp\刷量'
npm ci
npm run dev
```

开发模式会更新前端页面；修改 `server` 或 `shared` 后需重启服务。默认仅监听 `127.0.0.1`，不开放公网。

构建和运行稳定版：

```powershell
npm run build
npm start
```

前台启动时按 `Ctrl+C` 会保存数据、撤销模拟挂单并暂停机器人。后台启动后可在页面先点“全部暂停”，再关闭对应的 Node 服务进程。后台服务日志在 `work/server.out.log` 和 `work/server.err.log`。

| 客户要求 | 本版实现 |
| --- | --- |
| 每个币种单独建机器人 | 每合约只允许一个机器人，名称、金额、网格与风控独立；支持创建、编辑、暂停、启动与删除 |
| U 本位 | USDT / USDC 永续，两个模拟保证金账户分别核算；初始各 10,000 |
| 修改每格金额、数量、张数 | 固定 U 名义金额、固定币数量、自定义张数、账户权益百分比、可用余额百分比 |
| 每个币种一张金额不同 | 一张对应的基础币数量显式配置；U 本位接口实际数量单位是基础币，不假定统一张面值 |
| 移动网格 | 2–60 格、双侧各一半；固定价差或 bps；定时重设中心或突破区间后重设 |
| BTC 上下各 400、18 格、半小时移动 | 可在“网格与追价”中设置固定价差 400、18 格、30 分钟 |
| 只做 Maker | 所有订单都是本地 GTX / Post-only 语义限价单，无 MARKET / IOC / FOK 入口 |
| 撤单、重新挂单、追价 | 先撤后挂；至少 5 秒重报间隔、挂单有效期、全局滚动一分钟操作预算 |
| 平多 / 平空偏移不同 | 分别设置偏移值，支持固定 U 价差或 bps；价格按买一卖一约束为被动报价 |
| 成交额前 10 币种 | 每个保证金币种按 24 小时报价币成交额排序；支持批量创建，自动跳过已有合约 |
| 单边行情风控 | 同侧待成交量计入最坏持仓；持仓达到上限 80% 转只减仓；波动熔断、行情断流、亏损和回撤保护 |
| 挂单与历史查看 | 双侧挂单明细、剩余数量、模拟成交、手续费、持仓、风控日志与 JSON 导出 |
| 以后配置币安 API | 独立的 Demo / 正式环境只读连接检查；验证公开接口、账户认证、余额、持仓模式、保证金模式、持仓和费率，逐项展示结果 |

默认有 BTCUSDC、ETHUSDC、SOLUSDC 三个暂停的示例策略。新建和批量创建后也保持暂停，复核参数后手动启动。

## 配置并检查币安 API

这不是前端假数据演示：连接检查由 Node 服务端访问固定的币安 HTTPS 地址，执行 HMAC SHA256 签名和服务器时间校准。**当前真正实现的是读取，不是实盘交易执行。**

1. 在项目根目录复制 `.env.example` 为 `.env.local`；已有配置时编辑原文件，不要覆盖自己的密钥。
2. 选择 `BINANCE_READONLY_ENV=demo` 或 `production`，填写该环境对应的 HMAC API Key / Secret。Demo 与正式凭据不能混用；RSA / Ed25519 PEM 私钥不适用于本连接器。
3. 双击 `重启工作台.cmd`，进入页面的“使用指南与设置”。确认“检查环境”和“服务端凭据”显示符合预期。
4. 先不勾选账户读取，输入该环境支持的合约，例如 `BTCUSDT`，运行公开连接检查。
5. 配置专用读取凭据后，勾选“同时读取账户余额、持仓与费率”再检查。真实账户或 Demo 账户的数据会单独显示为一次性快照，不计入模拟账户。

配置示例（占位文字需自行替换，Secret 只保留在本机）：

```dotenv
BINANCE_READONLY_ENV=demo
BINANCE_READONLY_API_KEY=你的只读Key
BINANCE_READONLY_API_SECRET=对应的Secret
```

| 配置 | 固定地址 | 作用 |
| --- | --- | --- |
| `demo`（默认） | `https://demo-fapi.binance.com` | 读取 Binance Demo 环境 |
| `production` | `https://fapi.binance.com` | 读取正式环境；仍不允许交易或修改账户 |

检查环境与模拟器行情来源独立。模拟器的“币安公开行情”读取正式公开市场，不会因为上方选择 Demo 而混用 Demo 账户或价格。

| 检查内容 | 接口（全部为 GET） |
| --- | --- |
| 网络和时钟 | `/fapi/v1/time` |
| 可用 U 本位永续和数量 / 价格步长 | `/fapi/v1/exchangeInfo` |
| 买一卖一与标记价格 | `/fapi/v1/ticker/bookTicker`、`/fapi/v1/premiumIndex` |
| 账户余额 | `/fapi/v3/account` |
| 非零仓位及接口强平价 | `/fapi/v3/positionRisk` |
| 单向 / 双向持仓模式 | `/fapi/v1/positionSide/dual` |
| 单资产 / 多资产保证金模式 | `/fapi/v1/multiAssetsMargin` |
| 所选合约实际 Maker / Taker 费率 | `/fapi/v1/commissionRate` |

双向持仓、多资产保证金或已有仓位会单独提示；工具不更改这些设置，也不接管仓位。账户余额读取成功不代表所有子检查通过，更不代表下单权限或实盘执行已验证。

连接检查至少间隔 30 秒，每个请求最多 6 秒。时间误差使用服务器采样校准；收到 `-1021` 最多重新校准并重试一次。错误密钥、签名、权限、HTTP 451 地区限制、403 拒绝访问和超时分别显示。429 / 418 遵守 `Retry-After`，至少退避 60 / 120 秒；高请求权重保留余量。不会自动切换到其他域名、追随重定向或改用模拟结果冒充成功。

公开查询不携带 Key。Secret 仅由后端从环境读取，密钥不经网页输入、不返回浏览器、不写入模拟状态或导出记录；错误信息不回显带签名的 URL。账户报告仅保留在当前服务内存中，重启清空报告。`.env.local` 已被 Git 忽略，备份项目时仍需自行保管该文件。

### 本地检查接口

- `GET /api/binance/status`：当前配置状态、退避时间和最后报告；此接口本身不触发币安请求。
- `POST /api/binance/check`：严格接受 `{ "symbol": "BTCUSDT", "includeAccount": false }`，默认不读取账户；要求本机会话令牌和同源请求，返回 `202` 后后台执行。不能通过请求体传密钥、任意域名或订单参数。
- `GET /api/health`：显示 `version: "1.1.0"`、`binanceReadOnly: true`、`liveTrading: false`。

仍未实现的实盘环节包括订单提交与撤改、交易所订单状态同步、成交回报、断线后的持仓和订单对账、在途撤单竞态处理，以及交易所保证金与强平机制。所有只读项通过后，“实盘订单执行”仍明确显示“未实现”。

## 风控语义

- 每笔报价都校验价格步长、数量步长、最小数量、最大数量、最小名义金额与单笔限额。计算采用 Decimal，数量向下取整，不悄悄放大订单。
- 每格 U 金额是名义金额，**不会乘以杠杆**。杠杆仅用于估算模拟保证金。
- USDT 与 USDC 不互相借用。已有持仓、待成交开仓单、预估挂单手续费均占用相应预算。
- 同侧所有挂单可能先成交，再有机会对冲，因此不靠买卖挂单相互抵消来放宽限额。
- 只减仓订单在每次成交时按剩余仓位再次限制数量，不允许反向开仓。低于交易规则的尾仓保留，并提示无法挂出减仓单。
- 10 秒波动超限、无效盘口、标记价与盘口偏离或行情过期时，撤单并熔断。冷却结束不自动恢复。
- 全局日内亏损或权益回撤超限会锁定停止状态。日内基准在 UTC 00:00 更新，停止锁不自动解除。
- 暂停、熔断、紧急停止、修改参数均保留持仓。**撤单不等于平仓。**
- 紧急撤单不受普通报价频率额度阻塞。该额度用于模拟系统自我约束，不代表币安当前交易 API 限额。

## 模拟撮合的实际边界

只在**后续新盘口严格越过已有挂单价格**时模拟成交；同一快照不会重复撮合。每次仅使用盘口显示量的 10% 并支持部分成交。价格跳空时，先计算旧单可能成交造成的损失，再执行风控，避免假定撤单可以消除跳空风险。

这不是交易所级回测：没有模拟队列位置、真实逐笔成交、完整深度、资金费率、网络执行延迟、强平或保险基金。杠杆只是保证金估算。模拟结果不能证明实盘收益或安全性。

**Maker 单可能长时间无法成交。只挂单无法保证止损成功，也无法保证不爆仓。** 默认 1–10 倍模拟杠杆，不沿用截图中的 75–150 倍。

## 公开行情

只读取币安公开 USDⓈ-M 接口：

- `GET /fapi/v1/exchangeInfo`：交易状态、永续类型、保证金币种与交易规则；约每小时刷新。
- `GET /fapi/v1/ticker/24hr`：报价币成交额；每 60 秒刷新。
- `GET /fapi/v1/ticker/bookTicker`：买一卖一与数量。
- `GET /fapi/v1/premiumIndex`：标记价格。

盘口和标记价格每轮完成后至少间隔 3 秒再读取。仅保留每保证金币种前 10 名及已配置机器人关注的合约。出现错误会退避；429 / 418 至少等待 60 / 120 秒。保留并分别校验交易所时间戳，缺失、无效或过期时间不能被本地接收时间或另一条行情的时间伪装成新行情。缺失币种会保留最后标记价格用于展示估值，同时停用相关报价。

开发环境实际访问公开接口时收到了地区访问限制，因此没有完成真实行情端到端验证。接口解析、无效数据和错误退避通过离线测试；页面会如实显示连接错误，不绕过限制，不自动混入模拟行情。

切换数据源时必须无持仓，机器人统一暂停，以免拿不同来源的价格重估已有模拟仓位。

## 数据与运行

- `data/state.json`：参数、模拟钱包、持仓、最新行情、累计统计与记录。
- `data/state.json.bak`：上一次通过验证的备份；写入采用临时文件、刷新后原子替换。
- `data/runtime.lock`：阻止同一数据目录被两个实例同时写入。
- 恢复时验证数据；主文件损坏则使用有效备份。两者均无效时停止启动，绝不静默清空账户。
- 重启保留持仓和停止锁，机器人暂停；旧模拟挂单不会恢复。
- 每 5 秒保存一次，用户操作立即保存。异常断电最多可能丢失最后 5 秒模拟变化。
- 服务端最多保留 600 条事件、2,000 笔模拟成交；页面最多 200 条事件、200 笔全局成交，单机器人详情最多 50 笔。更长记录需要定期导出，当前没有无限审计归档。
- 应用只监听本机，写操作校验会话令牌与同源请求，限制请求体大小，并校验 Host。没有账户登录和多用户权限功能，不应直接改成公网监听。

新增 API 测试覆盖签名内容、服务器时间校准、时钟跳变、重试次数、固定域名与 GET 白名单、公开请求不带凭据、密钥与错误信息隔离、限流退避、过期 / 缺失行情、认证失败、双向和多资产模式、持仓 / 费率解析以及异步检查并发限制。账户认证的自动测试使用明确的测试替身；尚未使用客户的真实凭据完成验收。
